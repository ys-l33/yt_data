# YouTube Data Playground

개인이 발급받은 **YouTube Data API v3 키**로 채널·영상·댓글 지표를 추출하고 CSV로 내려받는 브랜드/인플루언서 분석 도구입니다.
서버 없이 브라우저에서만 동작하며, API 키는 브라우저에만 저장되고 Google API로 직접 전달됩니다.

## 기능

| 탭 | 하는 일 |
| --- | --- |
| **채널 분석** | 여러 채널(URL·@핸들·채널 ID)을 한 번에 비교. 구독자, 총 조회수, 최근 N개 영상의 평균/중앙값 조회수, 평균 좋아요·댓글, 참여율, 구독자 대비 조회율, 주간 업로드 수, 쇼츠 비중, 히트 영상 수, 조회수 편차. 행을 누르면 영상별 조회수 차트와 상세 표 |
| **영상별 비교** | 영상 URL 목록의 조회수·좋아요·댓글·참여율·일평균 조회수·구독자 대비 조회율과 합계 (캠페인/협찬 성과 보고용) |
| **키워드 검색** | 키워드로 영상 또는 채널을 검색하고(기간(직접 입력 가능)·지역·영상 종류(일반 영상/쇼츠)·정렬 조건) 지표를 붙여서 보여줌. 제목·설명·태그·채널명별로 제외할 단어 지정 가능. 결과에서 행을 직접 삭제(삭제 취소 가능)하고 "N건 더 검색하기"로 이어서 검색 가능. 결과 영상·채널을 영상별 비교·채널별 비교로 바로 보내기 가능 (인플루언서 발굴용) |
| **댓글 수집** | 영상 댓글 최대 3,000개 수집, 자주 쓰인 단어, 브랜드/제품 키워드 언급 수·비율 |
| **썸네일 다운로드** | 영상 링크로 썸네일을 크기별(최대 1280×720부터)로 미리 보고 다운로드. 여러 영상은 가장 큰 크기로 한 번에 받기 |
| **API 키 설정** | 키 저장·연결 테스트, 발급 방법 안내, 할당량 사용 기준 |

모든 표는 열 제목을 눌러 정렬할 수 있고, CSV는 엑셀에서 한글이 깨지지 않도록 저장됩니다.

배경은 서울의 현재 날씨([Open-Meteo](https://open-meteo.com), 키 불필요, 약 20분마다 갱신)에 맞춰 비·눈이 내리고, 흐림·밤에는 톤이 어두워집니다. 상단 "배경 움직임 끄기"로 끌 수 있으며, 주소 뒤에 `?weather=rain`(또는 `snow`, `cloudy`, `clear`, `&night=1`)을 붙이면 해당 날씨를 미리 볼 수 있습니다.

## 주요 지표 정의

- **참여율** = (좋아요 + 댓글) ÷ 조회수
- **구독자 대비 조회율** = 평균 조회수 ÷ 구독자 수 (중앙값 기준도 함께 제공)
- **히트 영상** = 중앙값의 2배 이상 조회된 영상 수
- **조회수 편차(CV)** = 표준편차 ÷ 평균 (낮을수록 안정적)
- **쇼츠 판별** = YouTube 기준인 "세로 또는 정사각형 + 3분 이하"(2024-10-15 이전 업로드는 1분 이하)를 API의 플레이어 화면비(`part=player`)와 길이로 확인. 화면비 정보가 없으면 60초 이하 또는 제목/설명에 `#shorts`가 있으면 쇼츠로 추정하고 `*`로 표시

YouTube Data API로는 공유 수, 시청 시간, 노출수, 클릭률, 시청자 연령·성별을 가져올 수 없습니다(채널 소유자 전용 Analytics API 영역). 구독자 수는 유효숫자 3자리로 반올림되어 제공됩니다.

## API 키 발급

1. [Google Cloud Console](https://console.cloud.google.com/)에서 새 프로젝트를 만듭니다.
2. **API 및 서비스 → 라이브러리**에서 **YouTube Data API v3**를 사용 설정합니다.
3. **사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키**를 선택합니다.
4. (권장) 키 제한에서 API를 YouTube Data API v3로, 웹사이트를 이 사이트 주소로 제한합니다.

무료 할당량은 하루 10,000 유닛입니다. 검색은 1회 100 유닛, 나머지 조회는 대부분 1 유닛이라 채널 분석은 채널당 2~5 유닛 정도면 됩니다.

## 실행 방법

### GitHub Pages로 배포 (추천)

저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치를 이 코드가 있는 브랜치의 `/ (root)`로 지정하면
`https://<사용자명>.github.io/yt_data/` 주소로 접속할 수 있습니다.

### 내 컴퓨터에서 실행

```bash
python3 -m http.server 8000
```

그 다음 브라우저에서 `http://localhost:8000`을 엽니다. API 키에 웹사이트 제한을 걸었다면 `http://localhost:8000/*`도 허용 목록에 추가하세요.

## 파일 구성

- `index.html` — 화면 구성
- `style.css` — 스타일 (라이트/다크 모드)
- `app.js` — API 호출, 지표 계산, 표·차트·CSV
