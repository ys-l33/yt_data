(01) — CHANNELS

채널 비교·분석

YouTube 기준에 따라 세로 또는 정사각형이면서 3분 이하인 영상을 쇼츠로 봅니다. 2024년 10월 15일 이전에 올라온 영상은 1분 이하가 기준입니다. 화면비와 길이는 API로 받은 값으로 확인합니다. (※ 화면비 정보가 없는 영상은 60초 이하이거나 제목·설명에 #shorts가 있으면 쇼츠로 추정하고, 형식 옆에 *를 표시합니다.)

분석할 영상을 고를 범위

선정 기준이 최근 업로드순이면 범위 안의 가장 최근 영상을, 조회수·좋아요·댓글 순이면 범위 안에서 그 수치가 높은 영상을 위 개수만큼 고릅니다. 범위가 넓을수록 영상 50개당 할당량이 약 2씩 더 듭니다.

여러 채널의 지표를 한 번에 모아 볼 때 유용합니다. 단일 채널 분석도 가능합니다.
지표 설명
참여율
(좋아요 + 댓글) ÷ 조회수. 분석 대상 영상 전체 합산 기준.
구독자 대비 조회율
평균 조회수 ÷ 구독자 수. 구독자 중 실제로 영상을 보는 비율의 근사치로, 구독자 수 “거품”을 가늠할 때 씁니다.
중앙값 조회수
한두 개 대박 영상에 평균이 왜곡되는 것을 막아 주는, 광고 단가 산정에 더 현실적인 기준입니다.
히트 영상
중앙값의 2배 이상 조회된 영상 수.
조회수 편차(CV)
표준편차 ÷ 평균. 낮을수록 영상별 성과가 안정적입니다.
선정 기준
최근 업로드순은 가장 최근 영상 N개를, 조회수·좋아요·댓글 순은 범위(기본: 최근 업로드 300개, “상세 설정”에서 변경) 안에서 그 수치가 높은 영상 N개를 분석합니다. 상위 영상만 모으므로 평균·참여율이 최근 업로드순보다 높게 나옵니다. YouTube가 채널 영상을 좋아요·댓글 순으로 주지 않아 범위 안의 영상을 모두 읽어 고르며, 영상 50개당 할당량이 약 2 사용됩니다.
주간 업로드
살펴본 범위의 영상 수 ÷ 그 기간(주). 최근 업로드 기준이면 가장 오래된 영상부터 오늘까지, 게시일 기준이면 지정한 기간으로 셉니다.
쇼츠 판별
YouTube 기준(세로 또는 정사각형 + 3분 이하, 2024년 10월 15일 이전 업로드는 1분 이하)에 따라 API로 받은 화면비와 길이로 판별합니다. 화면비 정보가 없는 영상은 60초 이하이거나 제목·설명에 #shorts가 있으면 쇼츠로 추정하고, 형식 옆에 *를 표시합니다.

구독자 수는 YouTube 정책상 유효숫자 3자리로 반올림되어 제공됩니다. 공유 수, 시청 시간, 노출수, 클릭률, 시청자 연령/성별은 채널 소유자만 볼 수 있는 YouTube Analytics 데이터라 이 도구로는 추출할 수 없습니다.

(06) — SETTINGS

API 키 설정

YouTube Data API 키

키는 서버로 전송되지 않고, 이 브라우저에서 Google API로만 직접 전달됩니다.

API 키 발급 방법 (약 5분)

  1. Google Cloud Console에 로그인하고 상단에서 새 프로젝트를 만듭니다.
  2. API 및 서비스 → 라이브러리에서 YouTube Data API v3를 검색해 사용을 누릅니다.
  3. API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키를 선택합니다.
  4. (권장) 생성된 키의 키 제한에서 API 제한을 YouTube Data API v3로, 웹사이트 제한을 이 사이트 주소로 설정합니다.
  5. 키를 복사해 입력란에 붙여넣고 저장하세요.

무료로 하루 10,000 유닛이 제공되며 태평양 시간 자정(한국 시간 오후 4~5시)에 초기화됩니다.

할당량 사용 기준

작업예상 유닛
채널 1개 분석 (최근 50개 영상)약 3
영상 50개 지표 조회약 2
댓글 100개 수집1
키워드 검색 50건약 102
URL이 아닌 채널명으로 채널 찾기100

검색은 비용이 크므로, 채널은 가능하면 URL이나 @핸들로 입력하세요.
